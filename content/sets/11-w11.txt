N: Scraping: dynamic JavaScript pages need browser automation (Selenium). Scrapers only see public data. A production pipeline has collection → normalization (flatten JSON/HTML to a fixed schema) → export layers, and deduplicates by tweet ID. Store tweet IDs as 64-bit integers or strings.
N: SEO: link farms manipulate link-based ranking (black hat); white hat = useful content that earns relevant links. PageRank propagates importance through the link graph instead of counting links.
N: APIs: Graph APIs model nodes + edges (traverse an edge to get connections; "paging.next" = next page). SOAP uses XML envelopes; REST is an architectural style, not a protocol; GraphQL lets clients choose fields. HTTP 429 = Too Many Requests; GET retrieves without changing state.

D: It increases the crawl budget legitimately
=: B

Q: A website receives thousands of backlinks from unrelated domains using nearly identical anchor text. Which SEO issue is most likely?
A: Keyword cannibalization
B: Link-spam / manipulative-link signal
C: Duplicate metadata
D: Crawl-depth optimization

?: Natural links vary in anchor text and come from related pages; identical anchors from unrelated domains look artificial.

Q: Which statement best distinguishes PageRank from simple backlink counting?
A: PageRank counts only links from the homepage
B: PageRank treats every backlink as having identical value
C: PageRank propagates importance through the link graph
D: PageRank ignores outbound links
=: C
?: A link from an important page counts for more, and outgoing links shape how importance flows.

Q: Which SEO practice is most likely to be considered legitimate white-hat optimization?
A: Buying thousands of backlinks
B: Creating hidden text containing keywords
C: Producing useful content and earning relevant backlinks
D: Creating doorway pages for search engines
=: C
?: White hat improves real usefulness; bought links, hidden text and doorway pages manipulate rankings.

Q: A Graph API represents data primarily as:
A: Sequential files
B: Tables only
C: Nodes and relationships/edges
D: Binary memory blocks
=: C
?: A user is a node connected to posts, followers and comments by edges, unlike foreign keys and joins in SQL.

Q: In a Graph API, which request concept is most appropriate for retrieving the connections of a particular object?
A: Traversing an edge/relationship
B: Dropping a table
C: Compiling a stored procedure
D: Creating an index file
=: A
?: For example, follow a user node's "posts" edge to get that user's posts.

Q: A Graph API response contains { "data": [...], "paging": { "next": "..." } }. What does the "next" field normally indicate?
A: Authentication failure
B: The next page of results
C: Database deletion
D: API version expiration
=: B
?: APIs return results in batches; the next URL or cursor fetches the following batch.

Q: Which property of a Graph API most directly distinguishes it from a conventional REST resource hierarchy?
A: It cannot use HTTP
B: It cannot return JSON
C: It emphasizes relationships between entities
D: It cannot support authentication
=: C
?: Graph APIs still use HTTP, JSON and auth; what's different is that relationships are first-class.

Q: Which protocol / format is most strongly associated with SOAP-based web services?
A: XML
B: CSV
C: JPEG
D: DNS
=: A
?: The SOAP envelope, header and body are XML. REST commonly uses JSON but doesn't require it.

Q: Which statement about REST is correct?
A: REST requires XML responses
B: REST requires SOAP envelopes
C: REST is an architectural style rather than a wire protocol
D: REST can only operate over TCP directly
=: C
?: REST (Representational State Transfer) is usually implemented over HTTP with GET/POST/PUT/PATCH/DELETE, but it is a style, not a protocol.

Q: Which API technology is particularly associated with allowing clients to specify precisely which fields they want?
A: GraphQL
B: FTP
C: SMTP
D: Telnet
=: A
?: The client's query describes the exact shape of data, avoiding over- and under-fetching.

Q: An API returns HTTP status code 429. What does this most commonly indicate?
A: Unauthorized request
B: Resource permanently deleted
C: Too many requests / rate limiting
D: Server successfully created an object
=: C
?: Clients should back off (often per a Retry-After header). 401 = unauthorized, 201 = created.

Q: Which HTTP method is generally intended to retrieve data without modifying server state?
A: GET
B: POST
C: DELETE
D: PATCH
=: A
?: POST creates or triggers processing, PATCH partially updates, DELETE removes.

Q: A scraper stores a tweet ID as an integer in a database. What problem can arise?
A: Tweet IDs can exceed the safe integer range of some systems
B: Tweet IDs always contain spaces
C: Tweet IDs cannot be indexed
