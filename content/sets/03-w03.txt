N: Facebook Inspector (FbI): browser plug-in sends a post ID → backend fetches it via the Graph API → 44 public features (entity, text, metadata, link) → two Random Forest models (one trained on URL-blacklist data, one on human annotation) → post is malicious if either flags it. Zero-hour detection, so no likes/comments/shares.
N: FbI numbers: cross-dataset accuracy only ~39–43%; ~65% of malicious posts still live months later; URL resolution was the slowest step; parallelizing cut response time 2.635 s → 1.893 s; ~1M posts checked in 9 months.
N: Cronbach's alpha = internal consistency of a questionnaire. Cohen's kappa = annotator agreement beyond chance. NDCG = ranking quality. A Likert item is ordinal data.
N: Privacy personas (Westin): Fundamentalist avoids sharing · Pragmatist weighs costs and benefits · Unconcerned shares freely.
