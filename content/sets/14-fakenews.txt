Q: In the "Components of Fake News" framework discussed in the course, an account that alternates between automated (bot-like) posting and manual human posting is classified as a:
A: Cyborg
B: Social Bot
C: Real Human
D: Sybil Account
=: A
?: A cyborg mixes automated posts with genuine manual activity, so it fits neither a pure-bot nor a pure-human profile.

Q: Which of the following is NOT typically considered one of the four "Generic Text Features" used in content-based fake news detection?
A: Lexicon
B: Syntax
C: Discourse
D: Cryptographic Hash
=: D
?: The four are lexicon, syntax, semantics and discourse; a hash is an integrity check, not a linguistic feature.

Q: Word2Vec primarily represents each word as:
A: A one-hot sparse vector based on vocabulary index
B: A dense low-dimensional vector learned from local context windows
C: A co-occurrence matrix factorized globally across the corpus
D: A contextualized vector that changes per sentence
=: B
?: CBOW / Skip-gram trained on local windows give one static dense vector per word.

Q: GloVe (Global Vectors for Word Representation) differs fundamentally from Word2Vec in that GloVe:
A: Uses only local context windows and ignores corpus statistics
B: Is trained using a global word-word co-occurrence matrix
C: Produces contextual embeddings that vary per sentence
D: Cannot be used for downstream semantic feature extraction
=: B
?: GloVe factorizes corpus-wide co-occurrence counts; Word2Vec learns from local windows. Both are static, unlike BERT.

Q: A defining architectural characteristic that distinguishes BERT from Word2Vec and GloVe is that BERT:
A: Produces a single static vector per word type across all contexts
B: Uses only forward (left-to-right) language modelling
C: Generates contextualized embeddings via a bidirectional Transformer encoder
D: Relies exclusively on co-occurrence matrix factorization
=: C
?: BERT's vector for a word changes with its sentence (masked LM + next-sentence prediction).

Q: In the taxonomy of "Latent Text Features" for fake news detection, Rhetorical Structure Theory (RST) is primarily used to model:
A: Word frequency distributions
B: Part-of-speech tag sequences
C: Coherence relations between discourse constituent parts of a text
D: Character-level n-gram statistics
=: C
?: RST splits text into discourse units joined by relations such as elaboration, contrast, cause and evidence.

Q: Regarding Context-Free Grammar (CFG) parse tree features in fake news detection research, which statement is most accurate?
A: CFG parse trees alone outperform all combined feature approaches
B: CFG parse tree-derived features consistently improve detection performance over baselines using only shallow lexico-syntactic features
C: CFG parse trees are irrelevant to fake news detection and only used for compiler design
D: CFG features can only be extracted from images, not text
=: B
?: Parse-tree production rules capture deeper structure than POS counts, and deceptive writing changes that structure.

Q: In lexical n-gram feature engineering, a "bigram" feature refers to:
A: A single isolated word treated independently
B: A contiguous sequence of two words (or tokens) treated as one unit
C: A pair of documents compared for similarity
D: A grammatical dependency parse between subject and object
=: B
?: An n-gram of order two, e.g. "breaking news"; a single word is a unigram.

Q: According to research on visual/image-based fake news characterization, the "image-to-tweet ratio" finding indicates that:
A: Fake news events contain more images per tweet than real news events
B: Real news events tend to contain more images than fake news events given the same number of tweets
C: Image-to-tweet ratio has no correlation with news veracity
D: Fake news never contains any images at all
=: B
?: For the same number of tweets, real events come with more distinct images (higher image-to-tweet ratio).

Q: The "Visual Clarity Score" as used in fake-news image analysis research is best described as a metric that:
A: Measures pixel-level sharpness and blur in an image
B: Measures the distribution difference between two image sets, with a bigger score indicating a more distinct target news image set
C: Counts the number of unique users who shared an image
D: Determines whether an image has been geotagged
=: B
?: Bigger score = the event's image set differs more from general images; fake events tend to score higher.

Q: In image forensics for fake news detection, the technique of comparing photo EXIF metadata between patches of an image is primarily used to detect:
A: Whether the image was taken with a flash
B: Image splicing, where content from two different real source images is combined
C: The geographic location where a tweet was posted
D: Whether an account is a bot
=: B
?: Different EXIF signatures in different patches suggest the photo was composited from two sources.

Q: Which of the following multimodal (multiple-modality-based) fake news detection methods explicitly employs an adversarial neural network component to learn event-invariant features?
A: SpotFake
B: MVAE
C: EANN
D: CredEye
=: C
?: EANN (Event Adversarial Neural Network) uses an adversarial event discriminator so features generalize across events.

Q: MVAE, as a multimodal fake news detection technique, is characterized by its use of:
A: A community-based crowdsourced rating system
B: A variational autoencoder that learns a shared latent representation from text and image modalities
C: A browser extension displaying real-time credibility scores only
D: An EXIF metadata comparison network
=: B
?: An encoder maps text + image to one shared latent space; a classifier sits on top of it.

Q: WhatsFarzi, developed at IIIT-Delhi under Prof. Ponnurangam Kumaraguru's supervision, is best described as a tool that:
A: Only detects fake video content
B: Analyzes text article authenticity using a knowledge graph and detects tampering in images uploaded by users
C: Is a WhatsApp group management application unrelated to fake news
D: Exclusively bans WhatsApp accounts sharing misinformation
=: B
?: Articles are checked against a knowledge graph of entity relations; uploaded images get a tampering check.

Q: CredEye's overall pipeline, upon receiving a textual claim, follows which general sequence of operations?
A: Directly classify the claim using only a pretrained sentiment model
B: Search the web for relevant articles, perform stance detection and content analysis, then aggregate credibility scores and extract supporting evidence
C: Only check whether the claim contains banned keywords
D: Encrypt the claim and forward it to a human fact-checker without automated analysis
=: B
?: Retrieve web articles → stance + content analysis + source trust → aggregated verdict with evidence snippets.

Q: Twitter's Birdwatch (community-driven misinformation labelling system) makes a note visible to the general Twitter audience on a tweet only when:
A: A single contributor submits a note
B: There is consensus from a broad and diverse set of contributors
C: Twitter's internal moderation team manually approves every single note
D: The tweet has more than one million impressions
=: B
?: Notes are first visible only to contributors; diverse agreement on helpfulness makes them public.

Q: The HawkEye paper primarily investigates Birdwatch's robustness with respect to:
A: Server uptime and latency issues
B: Robustness against adversaries who may manipulate ratings to influence note and tweet classification
C: The readability level of notes written by contributors
D: Twitter's advertising revenue model
=: B
?: Crowdsourced ratings can be gamed by fake or coordinated raters; HawkEye proposes a sturdier reputation system.

Q: TweetCred, developed by researchers including Ponnurangam Kumaraguru, was primarily deployed as:
A: A standalone mobile application only
B: A browser plug-in / Chrome extension that assigns real-time credibility scores to tweets in a user's timeline
C: A government surveillance tool
D: An offline batch-processing academic simulation never released to real users
=: B
?: A real-time Chrome extension: 1,127 users, ~5.4M tweets scored over three months.

Q: Facebook Inspector, as an extension of the TweetCred research lineage, primarily functions by:
A: Deleting fake posts automatically without user consent
B: Fetching post data through the Facebook Graph API, generating feature vectors, and applying supervised learning to assign and display a credibility label via a browser extension
C: Only monitoring private messages between users
D: Replacing Facebook's News Feed algorithm entirely
=: B
?: The browser extension sends the post URL; the back end fetches it via Graph API, scores it with a trained model and returns a label.

Q: The LIAR-PLUS dataset extends the original LIAR dataset by additionally providing:
A: Video transcripts of political debates
B: An automatically extracted justification for each statement's truthfulness label
C: Real-time streaming Twitter data
D: Image tampering annotations
=: B
?: LIAR has ~12.8K PolitiFact statements with six labels; LIAR-PLUS adds the fact-check's reasoning passage.

Q: The FA-KES dataset is specifically constructed around news articles concerning:
A: The COVID-19 pandemic globally
B: The Syrian civil war, with articles labelled true or false
C: US presidential elections
D: European Union economic policy

Q: The MediaEval 2015/2016 dataset, illustrated with examples such as spliced shark images during Hurricane Sandy, is primarily focused on:

Q: Regarding WhatsApp misinformation research methodology, "tiplines" are best defined as:
A: Automated bots that delete suspicious messages
B: Dedicated phone numbers to which WhatsApp users can forward suspicious content for evaluation by fact-checkers
C: Premium subscription services for verified news
D: Encrypted backup servers for WhatsApp chat history
=: B
?: Users forward suspicious messages to a WhatsApp number so fact-checkers can verify them — a window into private chats.

Q: In the "Credibility Ranking of Tweets during High Impact Events" research (Gupta & Kumaraguru), the machine learning approach used to rank tweets by credibility is best described as employing:
A: Unsupervised k-means clustering only
B: A ranking engine using RankSVM, trained on human-annotated ground truth with inter-annotator reliability measured via Cronbach's Alpha
C: A purely rule-based keyword blacklist system
D: Random forest regression on image pixel data only
=: B
?: Annotated tweets (agreement via Cronbach's alpha) train a RankSVM ranker, evaluated with NDCG.

Q: Based on the "Information Credibility on Twitter" research by Castillo, Mendoza, and Poblete, the study's core finding regarding Twitter's overall reliability was that:
A: Twitter messages are entirely fabricated and provide no reliable information
B: Most messages posted on Twitter are truthful, though the platform is also used to spread misinformation and false rumors, often unintentionally
C: Only verified accounts ever post truthful content
D: Twitter credibility cannot be modeled computationally at all
=: B
?: WWW 2011: most tweets are true, but rumours spread too, often by people who believe them.

Q: WhatsApp's fundamental architectural characteristics that differentiate it from platforms like Twitter or Facebook, as discussed in the course, include all of the following EXCEPT:
A: It functions primarily on a peer-to-peer / decentralized communication model without algorithmic content ranking

C: It uses an open, fully public content-recommendation algorithm to rank shared content
D: It is heavily multimedia-based, being primarily mobile-based with end-to-end encryption

Q: In the research on public WhatsApp groups, a key structural constraint on data collection is that:
A: There is no limit to the number of members a WhatsApp group can have

?: Groups hold at most 256 members and are joined via chat.whatsapp.com links; only ~10–20% of traffic is in groups.

Q: Considering the overall arc of "Practical Solutions to Combat Fake News" presented across the course (TweetCred, Facebook Inspector, WhatsFarzi, CredEye, Birdwatch/HawkEye), the most accurate high-level characterization of the progression and diversity of these solutions is that they collectively demonstrate:
A: A single universal algorithm that works identically and without modification across all platforms and content types
