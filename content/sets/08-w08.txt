N: Profile linking is probabilistic: matching attributes give evidence, not proof. Correlated features (username + display name) must not be double-counted. When visible attributes are changed on purpose, behavioural and temporal patterns remain the strongest signal.
N: Skewed data: a few heavy username-changers pull the mean up; the median better represents the typical user (0, 1, 1, 2, 20 → median 1, mean 4.8). Local clustering coefficient = links among neighbours ÷ k(k−1)/2.
N: Network models — Random (Erdős–Rényi): Poisson degrees, hubs extremely rare, short paths (~log N), small clustering. Small-world (Watts–Strogatz): short paths, large clustering. Scale-free (Barabási–Albert): power law P(k) ∝ k^−γ, hubs common via preferential attachment, short paths, rather small clustering. Hierarchical: power law, hubs connect modules, C(k) ~ k⁻¹, strong modularity.
N: Generic text features = lexicon, syntax (POS, CFG parse trees), semantics (Word2Vec/GloVe/BERT), discourse (RST). Word2Vec = static vectors from local windows; GloVe = global co-occurrence factorization; BERT = contextual, bidirectional Transformer encoder.
N: Tools: TweetCred (Chrome extension, real-time credibility; 1,127 users, 5.4M tweets) → Facebook Inspector (Graph API) → WhatsFarzi (knowledge graph + image tampering). CredEye = web search → stance + content → aggregated credibility + evidence. Birdwatch notes go public on diverse consensus; HawkEye studies robustness to rating manipulation.
N: Datasets: LIAR (~12.8K PolitiFact statements, 6 labels) and LIAR-PLUS (+ justification) · FA-KES (804 Syrian civil war articles) · NELA-GT-2021 (~1.8M articles, 367 outlets, 4th edition) · MediaEval 2015/16 (image verification) · FakeNewsNet (PolitiFact + GossipCop, adds spatiotemporal info).

Q: A researcher wants to know whether account A1 on Platform X and A2 on Platform Y belong to the same person. Username and photo differ, but they share the same city, employer, unusual posting schedule and several rare biographical details. Which inference is most scientifically defensible?
A: The accounts must belong to the same person because multiple attributes agree.
B: The accounts cannot belong to the same person because their usernames and photographs differ.
C: The combination of partially independent attributes can provide probabilistic evidence for linkage, but does not by itself establish identity with certainty.
D: Identity resolution is impossible unless the email address is identical.
=: C
?: Profile linking is probabilistic. Several matching attributes are strong evidence, but none of them proves identity on its own.

Q: A user deliberately changes their username, profile picture, biography, location and posting style across two platforms to prevent profile linking. Which feature is most likely to remain useful to an identity-resolution system?
A: Exact username matching
B: Exact profile-picture matching

D: Identical biography text
=: C

Q: In an anonymous network, each user interacts with many unrelated users, who rarely interact with one another. What structural property would you expect?
A: Very high local clustering coefficients.
B: Low clustering coefficients for many users.

Q: For a node i with kᵢ = 10 neighbours, only 9 of the possible kᵢ(kᵢ − 1)/2 neighbour–neighbour connections exist. What is the local clustering coefficient?
A: 9/10
B: 9/45
C: 10/45
D: 9/90
=: B
?: Maximum links among 10 neighbours = 10 × 9 / 2 = 45. Only 9 exist, so Cᵢ = 9/45 = 0.2.

Q: A network has high average degree, low clustering coefficient and short average path length. Which interpretation is most defensible?
A: Every user necessarily knows every other user.
B: Users may interact broadly without forming densely interconnected local communities.
C: The network must be a regular lattice.

=: B

Q: A network's degree distribution is approximately P(k) ∝ k^(−γ). Which statement follows most directly?
A: Every node has approximately the same degree.
B: High-degree nodes are impossible.
C: A small number of nodes can have exceptionally large degree compared with the majority.
D: The network must have exactly one connected component.
=: C
?: A power law means many low-degree nodes and a few hubs — the mark of a scale-free network.

Q: Two networks have degree distributions P1(k) ∝ e^(−λk) and P2(k) ∝ k^(−γ). For sufficiently large k, which generally allows a greater relative probability of extreme-degree nodes?
A: P1
B: P2
C: Both are identical asymptotically.
D: Neither can contain high-degree nodes.
=: B
?: An exponential falls off very fast; a power law has a heavier tail, so hubs are far more likely.

Q: A researcher plots degree on log-log axes, sees an approximately straight line over a limited range, and concludes "the network is definitively scale-free." What is the strongest criticism?
A: Log-log plots cannot be used for network data.

C: Scale-free networks cannot have hubs.
D: Power laws can only occur in directed networks.
=: B

Q: A defining architectural characteristic that distinguishes BERT from Word2Vec and GloVe is that BERT:
A: Produces a single static vector per word type across all contexts
B: Uses only forward (left-to-right) language modelling
C: Generates contextualized embeddings via a bidirectional Transformer encoder
D: Relies exclusively on co-occurrence matrix factorization
=: C
?: BERT's vector for a word changes with the sentence (masked LM + next-sentence prediction). A is Word2Vec/GloVe, D is GloVe.

Q: In the taxonomy of "Latent Text Features" for fake news detection, Rhetorical Structure Theory (RST) is primarily used to model:

?: RST splits text into discourse units linked by relations such as elaboration, contrast and evidence.
