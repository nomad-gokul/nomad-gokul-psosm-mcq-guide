Q: Which of the following best describes the Privacy Paradox?

B: Users express concern about privacy but still disclose personal information.

Q: Which type of attack attempts to obtain confidential information by manipulating users?
A: SQL Injection
B: Phishing
C: Buffer Overflow
D: DDoS
=: B
?: Phishing impersonates trusted organizations to trick people into revealing passwords, OTPs or bank details. It exploits human psychology, not software bugs.

Q: A developer initializes a local repository, commits changes, creates a GitHub repository, and wants to upload the local project for the first time. Which sequence is correct?
A: git clone → git add origin → git push
B: git remote add origin <URL> → git branch -M main → git push -u origin main
C: git remote -v → git pull origin main → git push
D: git fetch origin → git remote add origin → git commit
=: B
?: Add the remote, rename the branch to main if needed, then push and set upstream. git clone copies an existing remote; a pull isn't needed before the first push to an empty repo.

Q: After running `git remote add origin https://github.com/user/project.git`, which command verifies that the remote was added correctly?
A: git status
B: git log
C: git remote -v
D: git fetch
=: C
?: git remote -v lists configured remote URLs. git status shows working-tree state, git log shows commits, git fetch downloads changes.

Q: Your collaborator updates the remote repository while you modify your local copy. Which Git command is most appropriate before pushing your changes?
A: git status
B: git remote -v
C: git pull
D: git init
=: C
?: git pull downloads and merges the remote commits so you can resolve conflicts before pushing; otherwise the push is rejected.

Q: Which statement best explains why Python virtual environments improve reproducibility?
A: They increase execution speed.

C: They isolate project dependencies so the same package versions can be recreated.
D: They automatically optimize package installation.

?: Each project keeps its own packages; sharing requirements.txt lets others recreate the same versions.

Q: Which command switches to an existing branch named development?

Q: After editing three files, you execute `git add file1.py` and then `git commit -m "Update"`. What happens?
A: All modified files are committed.
B: Only file1.py is committed.
C: No files are committed.
D: Only tracked files are committed.
=: B
?: A commit includes only staged changes. The other two edited files stay modified in the working directory.

Q: According to Granovetter's "Strength of Weak Ties" theory, weak ties are valuable because they:
A: strengthen emotional support.
B: reduce communication costs.
C: connect individuals to otherwise disconnected social groups, providing novel information.
D: eliminate structural holes.
=: C
?: Close friends share the same circles and information. Acquaintances bridge different groups and bring new ideas and opportunities, such as job leads.

Q: A developer accidentally stages three files with `git add .` but wants to remove only config.py from the staging area while keeping its modifications. Which command should be used?
A: git reset --hard config.py
B: git restore config.py
C: git restore --staged config.py
D: git checkout config.py
=: C
?: --staged unstages the file but keeps the edits. reset --hard, restore and checkout discard the working-copy changes.

Q: Two developers modify the same line of a file in different branches. Git reports a merge conflict. What should be done next?
A: Delete the repository and clone again.
B: Resolve the conflicting code manually, stage the resolved file, and commit the merge.
C: Execute git push --force.
D: Run git init again.
=: B
?: Edit the file to keep the right changes, git add it, then commit the merge. Force-pushing or re-initializing doesn't resolve anything.

Q: Which statement correctly distinguishes git fetch from git pull?
A: Both commands are identical.
B: git fetch downloads remote changes without modifying the local branch, whereas git pull downloads and merges them.
C: git fetch uploads local commits, while git pull downloads commits.
D: git pull only works after git clone.
=: B
?: fetch lets you inspect incoming changes first; pull is fetch followed by merge (or rebase).

Q: A developer executes `git checkout a5f4d9b`, where a5f4d9b is a commit hash, not a branch name. What is the resulting state?
A: The repository becomes corrupted.
B: Git enters a detached HEAD state.
C: A new branch is automatically created.
D: The current branch is deleted.
=: B
?: Checking out a commit detaches HEAD so you can inspect it. New commits there belong to no branch unless you create one.

Q: `response = requests.get("https://example.com")`, then `print(response.status_code)` and `print(response.ok)`. The server returns HTTP 404. Which statement is correct?
A: response.ok will be True.
B: response.status_code will be "404" (string).
C: response.ok will be False while response.status_code will be 404.
D: The program automatically raises an exception.
=: C
?: status_code is the integer 404, and .ok is True only for codes below 400. requests raises nothing unless you call raise_for_status().

Q: What is the primary purpose of an authentication token in an OSN or web application?
A: To permanently store the user's password on the server.
B: To verify a user's identity after successful authentication and grant access to protected resources.
C: To encrypt all data stored in the database.
D: To increase the speed of internet communication.

Q: Which protocol provides secure communication over the Internet?
A: FTP
B: HTTP
C: TLS/HTTPS
D: SMTP
=: C
?: TLS encrypts traffic and HTTPS verifies the site with certificates. FTP, HTTP and SMTP are plain text by default.

Q: Metadata in social media may include:
A: Photo pixels only
B: User password
C: Location, timestamp, and device information

Q: Which of the following is an example of Personally Identifiable Information (PII)?
A: Browser cache
B: IP address
C: Name and Aadhaar number
D: CPU usage
=: C
?: Name plus Aadhaar uniquely identifies a person. An IP address can count as personal data under GDPR but is not the clearest identifier.

Q: Which attack creates multiple fake identities to influence a social network?
A: Replay Attack
B: Sybil Attack
C: Brute Force
D: Worm Attack
=: B
?: A Sybil attacker controls many fake identities. Replay resends captured data, brute force guesses passwords, a worm self-spreads.

Q: End-to-End Encryption ensures that:
A: Only the server can read messages.
B: Anyone with the URL can read messages.
C: Only the communicating users can read messages.
D: ISPs decrypt messages.
=: C
?: Messages are encrypted on the sender's device and decrypted only on the recipient's; servers and ISPs see ciphertext.

Q: Which principle minimizes the amount of collected user information?
A: Data Mining
B: Data Minimization
C: Data Duplication
D: Data Expansion
=: B
?: Collect only what a purpose needs — a weather app needs location, not contacts. It is a core GDPR principle.

Q: CAPTCHA is mainly used to:
A: Encrypt data
B: Detect automated bots
C: Improve bandwidth
D: Compress images
=: B
?: It separates humans from bots, blocking fake sign-ups, spam, credential stuffing and ticket bots.

Q: Differential Privacy primarily protects against:
A: Hardware failures
B: Re-identification of individuals in published datasets
C: SQL Injection
D: Password theft
=: B
?: Calibrated noise makes it hard to tell whether any one person's data is in the dataset while keeping aggregate statistics useful.

Q: Which statement about blockchain-based social media is TRUE?

B: Blockchain eliminates all cyber attacks.
C: Blockchain provides decentralization but does not automatically ensure user privacy.
D: Blockchain stores no user information.
=: C
?: Decentralization removes a single authority, but public ledgers are visible to anyone; privacy needs extra techniques.
